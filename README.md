# Aura Coffee

Landing page for Aura Coffee — a café by day / cocktail bar by night in Comayagua, Honduras.

## Structure

- `index.html` — single-file static site (HTML, CSS, and JS inline). No build step required.

## Deploying

This is a static site, so it can be deployed as-is on Vercel with zero configuration:

1. Import this repository into Vercel.
2. Leave the framework preset as "Other" (no build command / output directory needed).
3. Deploy — `index.html` is served directly from the project root.
